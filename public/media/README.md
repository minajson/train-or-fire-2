# Media

`machine-failure.mp4` goes here, if you have one.

The incident screen shows it when it is present and draws its animated
schematic when it is not. Nothing breaks either way — see
`docs/MACHINE_FAILURE_VIDEO_PROMPT.md` for the generation prompt and the
constraints the clip has to respect.

This directory is committed so the path exists; the video itself is not in the
repository.
